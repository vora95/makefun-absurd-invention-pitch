A small program that writes one sentence (164 characters) to `/output/entry.txt`: a pitch for a ridiculous invention that fixes a tiny everyday annoyance — a cereal bowl that keeps the milk and cereal in separate compartments until your spoon arrives, then introduces them with a tiny fanfare so nothing ever goes soggy.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no model calls, deterministic output.
